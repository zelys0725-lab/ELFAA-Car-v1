Hostinger VPS + Laravel Guide

ELFAA Car Rental Setup Guide

Complete, simplified guide to deploy your project, configure phpMyAdmin, import database, and launch.

Domain Name
elfaacarrental.online
Database Name
carkono
Git Repository
git@github.com:zelys0725-lab/ELFAA-Car-v1.git
1

Point Domain DNS to VPS

Log in to your Domain Registrar (Hostinger) → Go to DNS Zone for elfaacarrental.online and make sure these two A Records exist:

Type: A   | Name: @   | Points to: [YOUR_HOSTINGER_VPS_IP]
Type: A   | Name: www | Points to: [YOUR_HOSTINGER_VPS_IP]
ℹ️ Replace [YOUR_HOSTINGER_VPS_IP] with the actual IP address shown in your Hostinger VPS dashboard (e.g. 147.93.x.x).
2

Connect to Your VPS via PowerShell

Open Windows PowerShell on your computer and connect to your server:

ssh root@YOUR_HOSTINGER_VPS_IP

When asked for the password, type your VPS root password and hit Enter (no characters will appear on screen as you type, this is normal).

3

Install PHP 8.3, Nginx, MySQL & phpMyAdmin

Copy and paste this single script into PowerShell to install everything needed:

# Update OS packages
sudo apt update && sudo apt upgrade -y

# Add PHP 8.3 repository and install extensions
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y nginx mysql-server git curl unzip zip \
php8.3 php8.3-fpm php8.3-cli php8.3-mysql php8.3-curl php8.3-mbstring \
php8.3-xml php8.3-zip php8.3-bcmath php8.3-intl php8.3-gd

# Install Composer (PHP package manager)
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js 20 LTS (for React frontend)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# Install phpMyAdmin
sudo apt install -y phpmyadmin
⚠️ During phpMyAdmin installation:
1. When it shows web server options [ ] apache2 [ ] lighttpd, do not select either. Just press the TAB key to highlight <Ok> and press Enter.
2. When asked "Configure database for phpmyadmin with dbconfig-common?", select Yes and set a password.
4

Create MySQL Database & Open phpMyAdmin

Open MySQL on your server:

sudo mysql

Run these SQL statements (replace CarkonoPass2026! with your own password):

CREATE DATABASE carkono CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'carkono_user'@'localhost' IDENTIFIED BY 'CarkonoPass2026!';
GRANT ALL PRIVILEGES ON *.* TO 'carkono_user'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;

Now link phpMyAdmin so it opens in your web browser:

sudo ln -s /usr/share/phpmyadmin /var/www/html/phpmyadmin
🎉 Open phpMyAdmin now in your browser:
URL: http://YOUR_HOSTINGER_VPS_IP/phpmyadmin
Username: carkono_user
Password: CarkonoPass2026!

👉 Once logged in, click on carkono in the left list, click the Import tab at the top, select your computer's .sql file, and click Import!
5

Add SSH Key to GitHub & Clone Repository

Create an SSH key on your server for GitHub:

ssh-keygen -t ed25519 -C "elfaa-vps"

Press Enter 3 times (default file, no passphrase). Then print the key:

cat ~/.ssh/id_ed25519.pub

Copy the line printed (starts with ssh-ed25519 ...) and add it to your GitHub repo:

  1. Open your browser to: github.com/zelys0725-lab/ELFAA-Car-v1/settings/keys
  2. Click Add deploy key
  3. Title: Hostinger VPS → Paste key → Click Add key

Now clone your repo to /var/www/elfaa:

cd /var/www
git clone git@github.com:zelys0725-lab/ELFAA-Car-v1.git elfaa
cd /var/www/elfaa
6

Install Dependencies, Configure .env & Build React

Inside /var/www/elfaa, run:

cd /var/www/elfaa

# Install composer and node dependencies
composer install --no-dev --optimize-autoloader
npm install
npm run build

# Create production environment file
cp .env.example .env
nano .env

Update these lines in the .env file:

APP_NAME=ELFAA
APP_ENV=production
APP_KEY=
APP_DEBUG=false
APP_URL=https://elfaacarrental.online

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=carkono
DB_USERNAME=carkono_user
DB_PASSWORD=CarkonoPass2026!

Save and exit nano: Press Ctrl + O, then Enter, then Ctrl + X.

Now generate the app key and set folder permissions:

php artisan key:generate
php artisan storage:link
sudo chown -R www-data:www-data /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache
sudo chmod -R 775 /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache
7

Configure Nginx Web Server

Create the Nginx site configuration file:

sudo nano /etc/nginx/sites-available/elfaa

Paste the following complete configuration:

server {
    listen 80;
    server_name elfaacarrental.online www.elfaacarrental.online;
    root /var/www/elfaa/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php index.html;
    charset utf-8;

    # phpMyAdmin direct routing
    location /phpmyadmin {
        root /usr/share/;
        index index.php index.html;
        location ~ ^/phpmyadmin/(.+\.php)$ {
            try_files $uri =404;
            root /usr/share/;
            fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
            fastcgi_index index.php;
            fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
            include fastcgi_params;
        }
    }

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Save and exit (Ctrl + O, Enter, Ctrl + X). Then activate it:

sudo ln -s /etc/nginx/sites-available/elfaa /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
8

Install Free SSL Certificate (HTTPS)

Secure your website with free green lock HTTPS:

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d elfaacarrental.online -d www.elfaacarrental.online

Enter your email and agree to terms. Certbot will configure SSL automatically.

https://elfaacarrental.online

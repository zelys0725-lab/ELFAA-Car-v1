RECOMMENDED FOR DEMOS

Method 1: Instant Free Public Link (Cloudflare Tunnel)

This shares the website directly from your computer to the internet with a free public HTTPS link. Anyone in the room (or worldwide) can open it on their phones or laptops to test and grade your project!

1 Build your frontend assets

Open PowerShell in your ELFAA folder and build React:

npm run build
2 Start your Laravel server

In PowerShell, run:

php artisan serve --port=8000

(Keep this terminal window OPEN during your presentation)

3 Create the Free Public Link

Open a SECOND PowerShell window and run:

npx cloudflared tunnel --url http://127.0.0.1:8000

Cloudflare will generate a public link like: 

https://random-name-here.trycloudflare.com
✨ You're Live! Copy that URL and open it on your phone or send it to your evaluators/teachers. It has full HTTPS, working login, database, and React styling!
ALWAYS-ONLINE OPTION

Method 2: Free Cloud Hosting on Render.com

If you need the website to stay online 24/7 even when your laptop is turned off:

1 Push ELFAA to GitHub

Make sure your project is pushed to a private or public GitHub repository.

2 Create a Free Account on Render

Go to render.com and sign up using your GitHub account.

3 Deploy as Web Service

Click New + → Web Service → Connect your ELFAA GitHub repo.

  • Environment: PHP
  • Plan: Free ($0/mo)
  • Build Command: composer install --no-dev && npm install && npm run build
  • Start Command: php artisan serve --host 0.0.0.0 --port 10000

ELFAA Deployment Guide

Website Hosting & Setup Guide

A straightforward, beginner-friendly walkthrough to purchasing hosting and deploying your Laravel 11/13 + Inertia React application.

1 What You Need To Buy

Because ELFAA is built with modern Laravel + React (Inertia.js) and uses a backend queue/worker, standard cheap shared hosting will cause problems. You need a VPS (Virtual Private Server) and a Domain Name.

1. Custom Domain Name

~$10 - $14 / year

Your website address (e.g., elfaa.com or elfaa.org).

  • Where to buy: Namecheap, Cloudflare, or Hostinger
  • Easy DNS management
  • Free privacy protection included
Recommended

2. Cloud VPS Server

~$5 - $7 / month

A virtual Linux server where you have full control to run PHP 8.3, Nginx, Node, and MySQL.

  • Where to buy: Hostinger VPS (KVM 1 or 2) or DigitalOcean Droplet
  • Minimum Specs: 1 or 2 vCPU, 2GB RAM, Ubuntu 24.04 LTS
  • Dedicated IP address included
💡 Easiest Alternative: If you don't want to type Linux server commands, buy Cloudways (~$14/mo) or use Laravel Forge + DigitalOcean. It gives you a clean web dashboard that sets up PHP, SSL, and Git deployments automatically with 1 click.
2 Step-by-Step Setup Instructions
1

Connect Your Domain to Your Server IP

After buying your domain and VPS, go to your Domain Registrar's DNS settings (e.g. Namecheap / Cloudflare) and add an A Record:

Type: A
Name: @ (or elfaa.com)
Value: [Your VPS Public IP Address]
TTL: Automatic / 1 Hour

Add a second A record for www pointing to the same IP address.

2

Log in to Your Server via SSH

Open Windows PowerShell or Terminal and connect to your VPS using the root password provided by your hosting company:

ssh root@YOUR_SERVER_IP
3

Install PHP 8.3, Nginx, Composer & Node.js

ELFAA requires PHP 8.3, Composer, and Node.js. Run this command block on the server:

sudo apt update && sudo apt upgrade -y
sudo apt install -y nginx git curl unzip sqlite3 libsqlite3-dev
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y php8.3 php8.3-fpm php8.3-cli php8.3-curl php8.3-mbstring \
php8.3-xml php8.3-zip php8.3-bcmath php8.3-sqlite3 php8.3-intl php8.3-gd

# Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# Install Node.js (v20 LTS)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs
4

Download / Clone Your Project

Clone your ELFAA repository into the web folder:

cd /var/www
sudo git clone YOUR_GITHUB_REPO_URL elfaa
cd /var/www/elfaa

# Install PHP dependencies
composer install --no-dev --optimize-autoloader

# Install Frontend dependencies and build React assets
npm install
npm run build
5

Configure the Production .env File

Copy the environment file and generate the application encryption key:

cp .env.example .env
nano .env

Inside .env, change these important lines:

APP_ENV=production
APP_DEBUG=false
APP_URL=https://yourdomain.com

DB_CONNECTION=sqlite
# Make sure database/database.sqlite exists (or configure MySQL)

Exit nano (CTRL+O to save, CTRL+X to exit), then run:

# Create sqlite database file if it doesn't exist
touch database/database.sqlite

# Generate encryption key and run database tables
php artisan key:generate
php artisan migrate --force
php artisan storage:link

# Set correct folder permissions for Nginx
sudo chown -R www-data:www-data /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache /var/www/elfaa/database
sudo chmod -R 775 /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache
6

Configure Nginx Web Server

Create an Nginx configuration file for your website:

sudo nano /etc/nginx/sites-available/elfaa

Paste the following block (replace yourdomain.com with your actual domain):

server {
    listen 80;
    server_name yourdomain.com www.yourdomain.com;
    root /var/www/elfaa/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php;
    charset utf-8;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Enable the site and restart Nginx:

sudo ln -s /etc/nginx/sites-available/elfaa /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
7

Install Free SSL Certificate (HTTPS)

Protect your users and enable green padlock / HTTPS with free Let's Encrypt Certbot:

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com

Follow the prompts to provide your email. Certbot will configure SSL automatically!

8

Optimize Laravel for Speed

Cache your routes, config, and views so the website loads instantly:

php artisan config:cache
php artisan route:cache
php artisan view:cache

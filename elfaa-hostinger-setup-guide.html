Hostinger VPS Setup

ELFAA Car Rental Deployment Guide

Complete step-by-step instructions with phpMyAdmin, GitHub SSH, and SSL.

Domain Name elfaacarrental.online
Database Name carkono
Git Repository ELFAA-Car-v1
1

Point Domain DNS to Hostinger VPS

Go to your Domain Registrar (where you bought elfaacarrental.online) → DNS Management → Add these 2 records:

Type: A   | Name: @   | Value: [YOUR_HOSTINGER_VPS_IP]
Type: A   | Name: www | Value: [YOUR_HOSTINGER_VPS_IP]
DNS usually takes 5 to 15 minutes to propagate worldwide.
2

Connect to Your VPS via PowerShell

Open Windows PowerShell on your computer and connect as root:

ssh root@YOUR_HOSTINGER_VPS_IP

Type your root password when prompted (characters won't show on screen, just type and press Enter).

3

Install PHP 8.3, Nginx, MySQL & phpMyAdmin

Run this complete command on the server to install all packages:

# 1. Update server
sudo apt update && sudo apt upgrade -y

# 2. Add PHP repository & install PHP 8.3 with extensions
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y nginx mysql-server git curl unzip zip \
php8.3 php8.3-fpm php8.3-cli php8.3-mysql php8.3-curl php8.3-mbstring \
php8.3-xml php8.3-zip php8.3-bcmath php8.3-intl php8.3-gd

# 3. Install Composer
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer

# 4. Install Node.js 20 LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 5. Install phpMyAdmin
sudo apt install -y phpmyadmin
During phpMyAdmin installation:
1. When it asks for web server (apache2 or lighttpd), press TAB to select OK and press Enter (we will connect it to Nginx manually).
2. When asked "Configure database with dbconfig-common?", choose Yes and set a password.
4

Create 'carkono' Database & Access phpMyAdmin

Log in to MySQL terminal on the server:

sudo mysql

Run these SQL commands (replace StrongPassword123! with your own secure password):

CREATE DATABASE carkono CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'carkono_user'@'localhost' IDENTIFIED BY 'StrongPassword123!';
GRANT ALL PRIVILEGES ON *.* TO 'carkono_user'@'localhost' WITH GRANT OPTION;
FLUSH PRIVILEGES;
EXIT;

Now link phpMyAdmin so you can access it visually in your browser:

sudo ln -s /usr/share/phpmyadmin /var/www/html/phpmyadmin
🎉 You can now open phpMyAdmin in your browser!
Go to: http://YOUR_HOSTINGER_VPS_IP/phpmyadmin
Log in with: Username: carkono_user | Password: StrongPassword123!
Click on carkono on the left side, then click Import tab at the top to upload your existing .sql database file!
5

Connect GitHub via SSH

Generate a new SSH key on your VPS for GitHub:

ssh-keygen -t ed25519 -C "elfaa-vps"

Press Enter 3 times (default location, no passphrase). Then display the public key:

cat ~/.ssh/id_ed25519.pub

Copy the output, then:

  • Go to GitHub: https://github.com/zelys0725-lab/ELFAA-Car-v1/settings/keys
  • Click Add deploy key
  • Title: Hostinger VPS
  • Paste the key and click Add key.

Now clone the repository to /var/www/elfaa:

cd /var/www
git clone git@github.com:zelys0725-lab/ELFAA-Car-v1.git elfaa
cd /var/www/elfaa
6

Configure ELFAA .env & Build Assets

cd /var/www/elfaa

# Install composer and node packages
composer install --no-dev --optimize-autoloader
npm install
npm run build

# Create production .env
cp .env.example .env
nano .env

Inside .env, update these database & URL lines:

APP_NAME=ELFAA
APP_ENV=production
APP_DEBUG=false
APP_URL=https://elfaacarrental.online

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=carkono
DB_USERNAME=carkono_user
DB_PASSWORD=StrongPassword123!

Press CTRL+O then Enter to save, then CTRL+X to exit.

Now generate the key and set file permissions:

php artisan key:generate
php artisan storage:link

# Give Nginx permission to read & write storage/cache
sudo chown -R www-data:www-data /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache
sudo chmod -R 775 /var/www/elfaa/storage /var/www/elfaa/bootstrap/cache
7

Configure Nginx for elfaacarrental.online

Create the website configuration:

sudo nano /etc/nginx/sites-available/elfaa

Paste the following configuration:

server {
    listen 80;
    server_name elfaacarrental.online www.elfaacarrental.online;
    root /var/www/elfaa/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";

    index index.php index.html;
    charset utf-8;

    # phpMyAdmin support
    location /phpmyadmin {
        root /usr/share/;
        index index.php index.html;
        location ~ ^/phpmyadmin/(.+\.php)$ {
            try_files $uri =404;
            root /usr/share/;
            fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
            fastcgi_index index.php;
            fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
            include fastcgi_params;
        }
    }

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Enable the site and reload Nginx:

sudo ln -s /etc/nginx/sites-available/elfaa /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default
sudo nginx -t
sudo systemctl reload nginx
8

Activate Free SSL (HTTPS Green Lock)

Run Certbot to secure your domain with free HTTPS:

sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d elfaacarrental.online -d www.elfaacarrental.online

Type your email and agree to terms. Certbot will automatically install SSL!

🚀 Congratulations! Your website is now live at https://elfaacarrental.online!

👤 User Roles
The system has 4 distinct roles, each with specific access levels and responsibilities.
Admin

Administrator

Full system control. Manages all operations, users, settings, and configuration.

  • Manage all users & staff
  • Approve / reject bookings
  • Manage vehicle fleet
  • View financial reports
  • Configure SMTP & SMS
  • Manage promos & discounts
  • Review & verify documents
  • Access admin analytics
Client (Renter)

Verified Client

Registered renters who have been identity-verified and can create bookings.

  • Browse the vehicle fleet
  • Submit booking requests
  • Upload required documents
  • Track booking status
  • View booking history
  • Manage profile details
  • Cancel pending bookings
Customer (Guest)

Unverified Customer

Newly registered users pending identity verification before they can book.

  • View landing page & fleet
  • Create an account
  • Submit ID documents
  • Wait for Admin approval
  • Receive email notifications
Staff / Team

Operations Staff

Internal team members who assist with daily operational tasks and bookings.

  • View assigned bookings
  • Update booking statuses
  • Manage vehicle availability
  • Access team dashboard
🔐

Access Control Notice

Each role is enforced by server-side middleware (Laravel). A customer cannot access admin routes and vice versa. Document verification must be approved by an Admin before a customer is upgraded to a full Client account.

🔄 Booking Workflow
The complete lifecycle of a booking from creation to completion.
01

Register & Verify

Customer registers, uploads 3 required documents (License, Secondary ID, Proof of Billing).

02

Admin Verification

Admin reviews uploaded documents and approves the account, upgrading the user to Client status.

03

Create Booking

Verified Client selects a vehicle, dates, pickup location, and optionally applies a promo code.

04

Admin Review

Admin reviews the booking request and either approves it (with schedule) or rejects it with a reason.

05

Active Rental

On pickup date the booking becomes Active. Vehicle is marked unavailable for other bookings.

06

Completed

On return date the booking is marked Completed. Vehicle availability is restored.

📎 Required Documents for Verification
All 3 documents must be uploaded and approved before a customer can make a booking.
Document 1

🪪 Driver's License

A valid government-issued Driver's License is mandatory to prove the renter is legally authorized to drive.

  • Must be current and not expired
  • JPG, PNG, or PDF accepted
  • Max file size: 5MB
Document 2

📇 Secondary Photo ID

A second government-issued photo ID for dual identity verification (Passport, UMID, SSS, PhilHealth, etc.).

  • Must display full name & photo
  • JPG, PNG, or PDF accepted
  • Max file size: 5MB
Document 3

💡 Proof of Billing Address

A recent utility or bank statement to verify the renter's current address.

  • Meralco / Electricity bill
  • Water utility bill
  • Internet / cable bill
  • Bank statement
  • Must be within 3 months

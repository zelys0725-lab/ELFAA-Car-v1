Payment Settings
Setup Guide

Exactly what accounts to create, where to find each API key, and which field to paste it into — step by step for GCash (PayMongo) and Stripe.

📋 Overview 📱 GCash / PayMongo 💳 Stripe Cards ⚙️ Fill in the Fields 🔗 Webhooks 🧪 Test & Verify 🚀 Go Live
📋 Overview

What You Need to Do

The Payment Settings page (Admin Workspace → Payment Settings) lets you activate GCash and Stripe without touching any code. Here is the end-to-end checklist of what you need before filling in the fields.

📱
GCash via PayMongo

Create a free PayMongo account → get Test & Live API keys → register a webhook → paste keys into the GCash (PayMongo) tab.

💳
Stripe Card Payments

Create a free Stripe account → get Test & Live API keys → register a webhook → paste keys into the Stripe Cards tab.

✅
What Happens After

Once saved, the "Pay Online" button appears in the Customer Dashboard. Bookings auto-confirm when payment is received via webhook — no manual action needed.

⚠️
You can set up Test Mode and test everything with dummy numbers without a verified business account. You only need business verification to accept real money (Live Mode).
📱 Part 1 — GCash via PayMongo

Create a PayMongo Account & Get Your Keys

PayMongo is the payment gateway that processes GCash in ELFAA. You will create a free account, then copy 3 keys (Test Public Key, Test Secret Key, Test Webhook Secret) into the Payment Settings page.

1

Go to PayMongo and Sign Up

Open dashboard.paymongo.com/signup in your browser.

Fill in the registration form:
  • Full Name — your name as business owner
  • Email Address — use a business email you check regularly
  • Password — use a strong password
  • Mobile Number — for OTP verification
  • Business Name — e.g. ELFAA Car Rental
  • Business Type — select Transportation / Car Rental
ℹ️
PayMongo will send an email verification link. Open your email and click Verify Email before continuing. Check your spam folder if you don't see it.
2

Navigate to API Keys

After logging in, go to:

# Inside PayMongo Dashboard: Settings → API Keys

You will see a Test Keys section (immediately available) and a Live Keys section (available after business verification).

3

Copy Your API Keys

Copy each key shown below. You will paste them directly into the GCash tab of the Payment Settings page.

# Test Keys (available immediately): Test Public Key → pk_test_xxxxxxxxxxxxxxxxxxxx Test Secret Key → sk_test_xxxxxxxxxxxxxxxxxxxx # Live Keys (after KYB verification — for real payments): Live Public Key → pk_live_xxxxxxxxxxxxxxxxxxxx Live Secret Key → sk_live_xxxxxxxxxxxxxxxxxxxx
🔐
The Secret Key gives full access to your PayMongo account. Never paste it anywhere public, share it via chat, or commit it to GitHub. The ELFAA admin masks it after you save.
4

Create a Webhook & Copy the Webhook Secret

In the PayMongo Dashboard go to:

# Navigate to: Settings → Webhooks → Add Endpoint # Enter this exact URL (replace with your real domain): https://YOUR-DOMAIN.com/api/webhooks/paymongo # Select these 3 events to monitor: payment.paid payment.failed source.chargeable
After clicking Create:
  • PayMongo will show a Webhook Secret Key — it starts with whsk_
  • Copy it immediately (it is only shown once)
  • Paste it into Test Webhook Secret in the Payment Settings GCash tab
ℹ️
If your site runs on localhost during development, use ngrok.com to get a public URL first: run ngrok http 8000 then use the https://xxxx.ngrok.io URL as your webhook endpoint.
5

Verify Your Business (for Live Mode)

To accept real GCash payments you need KYB (Know Your Business) verification. Go to Settings → Account Verification and upload:

  • DTI or SEC Business Registration Certificate
  • BIR Certificate of Registration (Form 2303)
  • Valid government ID of the business owner
  • Business address proof (utility bill or lease agreement)
⚠️
Verification takes 3–7 business days. You can skip this for now and test with Test Mode keys first. Come back and add the Live Keys once verified.
💳 Part 2 — Stripe Card Payments

Create a Stripe Account & Get Your Keys

Stripe handles Visa, Mastercard, and Amex card payments. Create a free account and copy 3 keys (Test Publishable, Test Secret, Test Webhook Signing Secret) into the Stripe Cards tab of Payment Settings.

1

Go to Stripe and Sign Up

Open dashboard.stripe.com/register in your browser.

Fill in the registration form:
  • Email Address — your business email
  • Full Name
  • Password
  • Verify your email via the confirmation link Stripe sends
  • After login: select Country: Philippines
  • Business type: Individual or Company
  • Industry: Transportation → Car Rental
✅
Stripe gives you full test access immediately after email verification — no waiting, no business documents needed yet. You can copy your test keys and start testing right now.
2

Navigate to API Keys

In the Stripe Dashboard go to:

# Inside Stripe Dashboard: Developers → API Keys

At the top of the Stripe Dashboard there is a Test mode / Live mode toggle. Make sure you are in Test mode first to copy Test keys.

3

Copy Your Stripe API Keys

# In TEST MODE — copy these two keys: Test Publishable Key → pk_test_xxxxxxxxxxxxxxxxxxxx Test Secret Key → sk_test_xxxxxxxxxxxxxxxxxxxx (click "Reveal test key" to see it) # In LIVE MODE — copy these two keys (after verification): Live Publishable Key → pk_live_xxxxxxxxxxxxxxxxxxxx Live Secret Key → sk_live_xxxxxxxxxxxxxxxxxxxx (click "Reveal" to see it)
🔐
The Stripe Secret Key must be kept private. Never expose it in frontend code or share it. ELFAA only uses it server-side and masks it in the admin panel.
4

Create a Stripe Webhook Endpoint

In the Stripe Dashboard go to:

# Navigate to: Developers → Webhooks → Add Endpoint # Enter this URL (replace with your real domain): https://YOUR-DOMAIN.com/api/webhooks/stripe # Select these events to listen to: checkout.session.completed payment_intent.succeeded payment_intent.payment_failed charge.refunded
After the endpoint is created:
  • Click on the endpoint you just created to open it
  • Scroll down to Signing Secret and click Reveal
  • The secret starts with whsec_ — copy the whole value
  • Paste it into Test Webhook Secret in the Payment Settings Stripe tab
🔐
The Webhook Signing Secret is what proves an event actually came from Stripe. Without it, ELFAA cannot verify webhooks and bookings will NOT auto-confirm after payment.
5

Activate Your Stripe Account (for Live Mode)

To accept real card payments, click "Activate your account" on the Stripe Dashboard home. You will need to provide:

  • Valid government-issued ID (passport, driver's license, or TIN/SSS card)
  • DTI or SEC Business Registration Certificate
  • Tax Identification Number (TIN)
  • Your ELFAA website URL (must be live with HTTPS)
  • Philippine bank account for payouts (BDO, BPI, UnionBank, etc.)
⚠️
Stripe activation takes 1–3 business days. Use Test Mode in the meantime. Your website must be live and accessible when Stripe reviews it.

✅ Test the API Connection

Inside each gateway tab there is a "Test GCash API" or "Test Stripe API" button. Click it after entering your keys — a green popup means the keys are valid and the connection works.

💾 Save Payment Settings

Click the red "Save Payment Settings" button at the bottom. A success alert confirms the settings were saved to the database. The amber warning bar at the bottom shows when you have unsaved changes.

🔗 Webhook Setup

Webhook URLs to Register

Webhooks are how the payment provider tells ELFAA a payment was received. Without them, bookings will NOT auto-confirm. Register these exact URLs in both dashboards.

📱 PayMongo — GCash Webhook
https://YOUR-DOMAIN.com /api/webhooks/paymongo

Register at: Settings → Webhooks → Add Endpoint
Events: payment.paid  payment.failed  source.chargeable

💳 Stripe — Card Payments Webhook
https://YOUR-DOMAIN.com /api/webhooks/stripe

Register at: Developers → Webhooks → Add Endpoint
Events: checkout.session.completed  payment_intent.succeeded  payment_intent.payment_failed

⚠️
Important: Webhook URLs must be publicly accessible HTTPS URLs. If testing on localhost, use ngrok — run ngrok http 8000, then use the generated https://xxxx.ngrok.io URL as your webhook endpoint. Remember to update the URL when you go live on a real domain.
🔎
Local Stripe Webhook Testing (Stripe CLI method):
# Install Stripe CLI, then run: stripe login stripe listen --forward-to localhost:8000/api/webhooks/stripe # Use the webhook secret the CLI prints in the admin Test Webhook Secret field # Trigger a test event: stripe trigger checkout.session.completed

🚀 Go Live Checklist

Switching to Live Mode

When you're ready to accept real payments, follow this checklist. Go through it item by item before switching your Payment Settings to Live Mode.

1

Confirm Business Verification is Approved

Check both PayMongo Dashboard and Stripe Dashboard for any pending items. Both must show a Verified or Active account status. Stripe also requires your business website to be live at this point.

2

Register Live Webhook Endpoints

In both PayMongo and Stripe, create new webhook endpoints using your real production HTTPS domain. Copy the new Live Webhook Secrets for each provider.

# Production webhook URLs: https://elfaacarrental.com/api/webhooks/paymongo https://elfaacarrental.com/api/webhooks/stripe
3

Enter Live Keys in the Admin Dashboard

Go to Payment Settings in the admin. In each gateway tab fill in the Live Production Keys section with your pk_live_, sk_live_, and live webhook secret. Then switch Processing Mode to Live Mode and save.

🔐
Triple-check that you're pasting Live Keys (not Test Keys) into the Live fields. Mixing them up causes payment failures for real customers.
4

Run One Real Test Payment

Make a small real payment using an actual GCash account or real credit card. Confirm the transaction appears in the ELFAA admin and in the provider's live dashboard. Then refund yourself if needed.

✅
Once the live payment confirms and the booking auto-confirms in admin — you're fully live. Payments are active for customers.
5

Monitor & Emergency Rollback

  • Check Admin Bookings Log — booking statuses update after payment
  • Check PayMongo / Stripe webhook delivery logs — all responses should be 200 OK
  • If payments break: go to Payment Settings → toggle the gateway to Disabled → Save — this instantly removes the Pay Online button for customers with zero downtime

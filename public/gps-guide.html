System Architecture

How the GPS Tracking System Works

For your thesis and real-world rental operations, you do not need expensive OBD-II hardware or dedicated satellite blackboxes. ELFAA turns any Android or iPhone smartphone into an accurate real-time GPS telemetry beacon.

📱
1. Mobile Phone

Mounted inside the vehicle dashboard. HTML5 Geolocation reads GPS coordinates every 3 seconds.

navigator.geolocation
📡
2. Transmitter Ping

Sends JSON payload containing coordinates, speed, and heading to the ELFAA backend.

POST /api/gps/ping
🗄️
3. Laravel Database

Validates 32-char security key, updates vehicle live status, and stores trail in history log.

vehicles + vehicle_gps_logs
🗺️
4. Admin Leaflet Map

Admin dashboard automatically polls latest coordinates every 8 seconds and moves car pins smoothly.

Leaflet + OpenStreetMap
⚡

Real-Time Speed & Heading

The transmitter calculates instantaneous speed in km/h directly from satellite Doppler shift and compass heading in degrees, rendering moving rotation angles on the map.

🔒

Cryptographic Security Key

Every vehicle receives an unguessable 32-character tracker token (e.g., k8Fa9...). Only requests presenting this key can update telemetry, preventing spoofing.

🔋

Screen Wake Lock API

The mobile transmitter uses the modern Web Screen Wake Lock API to prevent the phone display from sleeping while driving, ensuring uninterrupted telemetry pings.

Prerequisites & Setup

What Need to Install? (Zero Hidden Installs)

One of the greatest advantages of this implementation is simplicity. You do not need complex third-party software, paid Google Maps accounts, or heavy hardware.

✅

What You DO Need (Already in the App)

  • Laravel Backend: Running on your computer (php artisan serve).
  • MySQL Database: Tables vehicles and vehicle_gps_logs (already migrated).
  • Smartphone with GPS: Any modern Android or iOS phone with location services toggled on.
  • Modern Mobile Web Browser: Google Chrome, Safari, or Microsoft Edge.
🚫

What You DO NOT Need

  • NO Google Maps API Key: We use free, open-source OpenStreetMap with zero billing or credit cards.
  • NO npm/composer map package: Leaflet 1.9.4 is loaded dynamically from CDN in the browser.
  • NO App Store downloads required: The primary transmitter is a lightweight web application that runs directly in the browser.
  • Tesseract OCR is NOT for GPS: Tesseract is only used for Driver's License verification. GPS requires zero OCR binaries!
💡
Why Leaflet + OpenStreetMap instead of Google Maps? OpenStreetMap tiles are completely free, have no usage quotas or surprise monthly invoices, and load instantly via CDN without configuring Google Cloud Console credentials or restrictive API domain keys.

How Can I Configure GPS for a Car?

Follow these simple steps in the ELFAA Admin Portal to activate GPS tracking on any vehicle in your inventory.

1

Navigate to Admin Dashboard > Fleet Inventory

Log in with an administrator account (admin@elfaa.com). In the main dashboard tabs, click on Fleet Inventory to view all registered rental cars.

Admin Portal
2

Click "Edit" on Target Vehicle

Locate the car you want to track (e.g., Toyota Vios 2023) and click the pencil Edit button. The vehicle modal will open.

Fleet Management
3

Scroll to "GPS Live Tracking" Section

Inside the edit modal, find the dedicated GPS configuration panel with the satellite dish icon.

  • Enable GPS: Click the toggle switch to turn it ON.
  • GPS Device ID: Enter a friendly identifier (e.g., ELFAA-GPS-001).
Configuration
4

Copy the "Smartphone Transmitter URL"

As soon as GPS is enabled, the system automatically assigns a secure 32-character gps_tracker_key. A read-only URL box will display:

Click the Copy URL button or click Open Transmitter to test directly.

Save Vehicle

Click "Save Vehicle" at the bottom of the modal. The vehicle is now live and waiting for satellite pings from the phone!

Mobile Telemetry

Using the Smartphone as In-Car GPS Transmitter

Here is how to set up the phone inside the rental vehicle on the day of the test or rental trip.

🌐

Option A: Web Transmitter (Recommended)

No downloads or apps needed. Uses modern web APIs inside Chrome or Safari.

  1. Send the copied /tracker/{key} link to the phone (via SMS, QR code, or chat).
  2. Open the link in Chrome (Android) or Safari (iPhone).
  3. When prompted: tap "Allow" for Location Permissions.
  4. Choose your Ping Interval: 3 seconds is recommended for fluid tracking.
  5. Tap the big green button: "Start GPS Transmission".
  6. Mount the phone in the car holder. The screen will stay awake automatically!
📲

Option B: Traccar Client App (Optional Alternative)

If you prefer a standalone background native app, ELFAA fully supports the industry-standard Traccar Client protocol.

  1. Download Traccar Client for free on Google Play or iOS App Store.
  2. Set Server URL to: http://YOUR_IP:8000/api/gps/traccar
  3. Set Device Identifier to: your car's GPS Device ID (e.g., ELFAA-GPS-001).
  4. Set Frequency to: 5 to 10 seconds.
  5. Turn the Service Status switch to ON.
⚠️
Important Battery Tip for Road Testing: High-frequency GPS tracking (every 1 to 3 seconds) with screen awake uses significant phone battery. Always plug the smartphone into the vehicle's 12V USB charger during long driving tests.
Networking Guide

Local WiFi vs. Public Access (Crucial for Thesis Defense)

When testing on your phone, you must understand how your mobile device connects to your development computer.

🏠

Method 1: Local WiFi (Same Router)

Best for testing in your room or classroom where both laptop and phone share the same WiFi network.

# 1. Find your computer's local IP (Windows) ipconfig # Look for IPv4 Address: e.g. 192.168.1.15 # 2. Start Laravel binding to all network interfaces php artisan serve --host=0.0.0.0 --port=8000

On your phone browser, open: http://192.168.1.15:8000/tracker/YOUR_KEY
⚠️ Never use localhost:8000 on your phone — "localhost" on a phone refers to the phone itself!

🌍

Method 2: Ngrok HTTPS Tunnel (Best for Road Test)

Required when driving outside away from home WiFi, using phone cellular data (4G/5G).

# 1. Download & run free ngrok tunnel ngrok http 8000 # 2. Copy the public HTTPS forwarding URL: https://xyz123.ngrok-free.app

Open: https://xyz123.ngrok-free.app/tracker/YOUR_KEY on your phone anywhere in the city. The GPS coordinates will instantly stream back to your laptop!

✨
HTTPS Bonus: Mobile browsers grant HTML5 Geolocation and WakeLock permissions much smoother over secure https:// tunnels!

2. Historical Breadcrumb Table (vehicle_gps_logs)

Schema::create('vehicle_gps_logs', function (Blueprint $table) { $table->id(); $table->foreignId('vehicle_id')->constrained('vehicles')->cascadeOnDelete(); $table->decimal('latitude', 10, 7); $table->decimal('longitude', 10, 7); $table->decimal('speed', 6, 2)->default(0); // in km/h $table->decimal('heading', 6, 2)->nullable(); // 0 to 360 degrees $table->timestamp('recorded_at')->useCurrent(); // precise moment of ping $table->timestamps(); $table->index(['vehicle_id', 'recorded_at']); // fast route querying });

Troubleshooting & FAQ

Troubleshooting & Thesis Defense Q&A

Here are solutions to the most common setup questions and answers you can give to your thesis panel.

1. The phone says "Location Permission Denied" or fails to acquire coordinates. ▼
Check the following:
  1. Ensure Device Location / GPS is turned ON in the phone's Android/iOS top drawer.
  2. In your mobile browser (Chrome/Safari), tap the lock or tune icon in the address bar > Permissions > Location > Allow.
  3. If testing indoors, move closer to a window. Concrete buildings can block GPS satellite reception, causing the browser to timeout.
2. The car appears as "Offline" on the Admin Map. ▼
A car is marked "Offline" if the system has not received a ping in the last 2 minutes. Tap "Start GPS Transmission" on the phone and check the Pings Sent counter. As soon as the next ping arrives, the status badge will immediately turn into an active green "Moving" or amber "Idle" pill.
3. How can I simulate GPS movement inside the classroom for my thesis demo? ▼
You can simulate realistic car movement without actually driving!
  • In Google Chrome (Desktop): Open /tracker/{key} > Press F12 > Click the 3 dots menu > More tools > Sensors > Choose a preset location (e.g. San Francisco or Manila) or enter custom lat/long. Tap "Start GPS Transmission" and change coordinates slightly to see the car move on the admin map!
  • On Android Phone: Download any free "Fake GPS location" app from Google Play > Enable Developer Options > Set Mock Location App. You can simulate driving along any road in real-time.
4. Thesis Defense: "Why did you build web-based phone tracking instead of buying hardware trackers?" ▼
Recommended Panel Response: "Hardware trackers (OBD-II dongles or 4G GPS modules) cost ₱2,500 to ₱5,000 per unit, plus monthly cellular SIM subscriptions. By designing a progressive web telemetry transmitter using the HTML5 Geolocation API, ELFAA achieves zero hardware acquisition cost. Fleet owners can repurpose any existing budget smartphone or tablet already placed in the vehicle, while maintaining cryptographic security and sub-3-second latency."
5. Is my GPS ping blocked by CSRF protection? ▼
No. In bootstrap/app.php, the ELFAA application explicitly configures $middleware->validateCsrfTokens(except: ['api/*', ...]). The endpoints /api/gps/ping and /api/gps/traccar are exempted from session cookies and authenticated via the vehicle's unique 32-character tracker token.

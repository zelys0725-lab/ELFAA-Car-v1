📋 Overview

How Payments Work in ELFAA

ELFAA supports two payment providers out of the box. Each gateway works independently — you can enable one or both. All settings are managed from the admin dashboard without touching code.

Philippines
📱

GCash via PayMongo

Accept GCash e-wallet payments from Filipino customers. Powered by PayMongo's secure checkout. Customers pay via QR code or GCash mobile OTP. Free to create an account — fees are per transaction only.

Global
💳

Stripe Card Payments

Accept Visa, Mastercard, American Express, and more. Used for international card payments. Industry-standard, developer-friendly, with strong fraud protection and PCI-DSS compliance.

Automated
🔗

Webhook Auto-Confirmation

Both gateways send real-time payment notifications to ELFAA via webhooks. Booking statuses are automatically updated to Confirmed once payment is verified — no manual action needed.

📱 Part 1 of 3 — GCash Gateway

Setting Up GCash via PayMongo

PayMongo is the payment provider that powers GCash checkout in ELFAA. Follow these steps to create your account, verify your business, and retrieve the API keys needed for the admin dashboard.

1

Create a PayMongo Account

Go to dashboard.paymongo.com/signup and register for a free account.

Registration Details Required:
  • Your full name and email address
  • Mobile number (for OTP verification)
  • Business name (e.g., ELFAA Car Rental)
  • Business type: select Transportation / Car Rental
ℹ️
After signing up, PayMongo will send an email verification link. Click it to activate your account before proceeding.
2

Complete Business Verification (KYB)

To accept real GCash payments, PayMongo requires business verification. This is only needed for Live mode. You can skip this and use Test mode for now.

Documents you will need to upload:
  • DTI / SEC Business Registration Certificate
  • BIR Certificate of Registration (Form 2303)
  • Valid government ID of the business owner
  • Business address proof (utility bill or lease agreement)
  • Mayor's Permit or Business Permit (if applicable)
⚠️
Verification can take 3–7 business days. Plan ahead if you have a launch deadline. Use Test mode in the meantime to configure and test everything end-to-end.
3

Get Your PayMongo API Keys

Once logged in, navigate to the API Keys section. PayMongo provides two sets — one for testing, one for live payments.

# PayMongo Dashboard Navigation: Dashboard → Settings → API Keys
Keys you need to copy:
  • Test Public Key — starts with pk_test_
  • Test Secret Key — starts with sk_test_
  • Live Public Key — starts with pk_live_ (after verification)
  • Live Secret Key — starts with sk_live_ (after verification)
🔐
Secret Keys are sensitive! Never share Secret Keys publicly, commit them to Git, or expose them in the browser. ELFAA stores them encrypted in the database and masks them in the admin UI.
4

Set Up a PayMongo Webhook

Webhooks allow PayMongo to notify ELFAA automatically when a GCash payment is completed. Without this, bookings will not auto-confirm.

# PayMongo Dashboard Navigation: Dashboard → Settings → Webhooks → Add Endpoint # Your ELFAA Webhook URL: https://yourdomain.com/api/webhooks/paymongo # Events to subscribe: payment.paid payment.failed source.chargeable
After creating the webhook:
  • Copy the Webhook Secret key that PayMongo generates
  • It starts with whsk_
  • Paste it into ELFAA Admin: Payment Settings → GCash tab → Test Webhook Secret Key
ℹ️
If your site is on localhost, use ngrok to get a public URL for webhook testing: run ngrok http 8000 and register the ngrok URL.
5

Add a Settlement Bank Account

Once live, collected payments are transferred to your bank account. Add your business bank account in the PayMongo Dashboard to enable payouts.

# Navigate to: Dashboard → Payouts → Add Bank Account # Supported banks (Philippines): BDO, BPI, Metrobank, UnionBank, RCBC, PNB, Security Bank, etc.
✅
PayMongo supports InstaPay for same-day settlements to supported banks. Settlements are typically processed every business day (T+1).
💳 Part 2 of 3 — Stripe Gateway

Setting Up Stripe Card Payments

Stripe lets customers pay with their credit or debit card (Visa, Mastercard, Amex). It offers a full test environment — you can start integrating immediately without waiting for business approval.

1

Create a Stripe Account

Visit dashboard.stripe.com/register and create a free account. No credit card required to sign up.

During Registration:
  • Enter your email address and create a secure password
  • Verify your email via the confirmation link Stripe sends
  • Country: select Philippines
  • Business type: Individual or Company
  • Industry: Transportation → Car Rental
✅
You can access Stripe's full test environment immediately after email verification, before completing business verification. Start building and testing right away.
2

Activate Your Stripe Account (for Live Mode)

To accept real card payments, complete Stripe's identity and business verification. Click "Activate your account" in the Stripe Dashboard home page.

Documents Required:
  • Valid government-issued ID (passport, driver's license, SSS/PhilHealth/TIN card)
  • Business registration documents (DTI or SEC Certificate)
  • Tax Identification Number (TIN)
  • Business website URL (your live ELFAA domain)
  • Bank account details for payouts (BDO, BPI, UnionBank, etc.)
⚠️
Stripe verification for Philippine accounts typically takes 1–3 business days. Make sure your business website is live and functional during the review — Stripe will check it.
3

Retrieve Your Stripe API Keys

Go to the Stripe Dashboard and navigate to the API Keys section. Stripe provides two separate environments — Test and Live.

# Stripe Dashboard Navigation: Dashboard → Developers → API Keys
Keys you need to copy:
  • Test Publishable Key — starts with pk_test_
  • Test Secret Key — starts with sk_test_ (click "Reveal")
  • Live Publishable Key — starts with pk_live_
  • Live Secret Key — starts with sk_live_ (click "Reveal" in Live mode)
ℹ️
Use the Test/Live toggle at the top of the Stripe Dashboard to switch between viewing test and live keys. Make sure you're in the correct environment when copying keys.
4

Create a Stripe Webhook Endpoint

Register your ELFAA webhook URL in Stripe so that card payment confirmations are automatically sent to your system.

# Stripe Dashboard Navigation: Dashboard → Developers → Webhooks → Add Endpoint # Your ELFAA Webhook URL: https://yourdomain.com/api/webhooks/stripe # Events to subscribe (select these exactly): checkout.session.completed payment_intent.succeeded payment_intent.payment_failed charge.refunded
After creating the webhook endpoint:
  • Click the endpoint to open its details page
  • Under Signing Secret, click Reveal
  • Copy the secret — it starts with whsec_
  • Paste it into ELFAA Admin: Payment Settings → Stripe tab → Test Webhook Secret
🔐
The Stripe Webhook Signing Secret is critical for security. ELFAA uses it to verify that webhook events genuinely came from Stripe and haven't been tampered with. Without it, anyone could fake a payment confirmation.
5

Add Your Bank Account for Payouts

Configure your Philippine bank account in Stripe for automatic weekly payouts.

# Navigate to: Dashboard → Balance → Payouts → Add Bank Account # Accepted banks (Philippines): BDO, BPI, UnionBank, RCBC, Security Bank, Metrobank, etc. Also supports GCash and Maya payouts.
⚙️ Part 3 of 3 — Admin Dashboard

Configuring Payments in the Admin Dashboard

Once you have your API keys from PayMongo and/or Stripe, enter them in the ELFAA admin dashboard. Navigate to Payment Settings in the left sidebar of the Administrator Workspace.

1

Open Payment Settings

Log in as an admin and click Payment Settings in the left navigation sidebar. You'll see three overview cards at the top showing the current status of each gateway.

The three overview cards show:
  • GCash (PayMongo) — shows Active/Disabled badge, environment (TEST/LIVE), and credential status
  • Stripe Card Pay — shows Active/Disabled, environment, and credential status
  • Auto-Confirmation — shows post-payment automation and currency
2

Configure GCash (PayMongo) Tab

Click the GCash (PayMongo) tab and fill in the fields below with your PayMongo credentials.

Field Where to Find It Status
GCash Gateway Status Toggle switch to Enabled to activate Required
Processing Mode Set to Test Mode while testing; switch to Live Mode for production Required
Test Public Key PayMongo Dashboard → Settings → API Keys → Public Key (Test) Required
Test Secret Key PayMongo Dashboard → Settings → API Keys → Secret Key (Test) Required
Test Webhook Secret Key PayMongo Dashboard → Settings → Webhooks → Webhook Secret (whsk_...) Required
Live Public Key PayMongo Dashboard → API Keys → Public Key (Live) — available after KYB verification Live Only
Live Secret Key PayMongo Dashboard → API Keys → Secret Key (Live) Live Only
Live Webhook Secret Key PayMongo Dashboard → Webhooks → Live Webhook → Webhook Secret Live Only
3

Configure Stripe Cards Tab

Click the Stripe Cards tab and fill in your Stripe API keys.

Field Where to Find It Status
Stripe Gateway Status Toggle switch to Enabled Required
Processing Mode Set to Test Mode initially Required
Test Public Key Stripe Dashboard → Developers → API Keys → Publishable key (Test) Required
Test Secret Key Stripe Dashboard → Developers → API Keys → Secret key (click Reveal) Required
Test Webhook Secret Stripe Dashboard → Developers → Webhooks → Your Endpoint → Signing Secret Required
Live Public Key Stripe Dashboard → Toggle to Live mode → API Keys → Publishable key Live Only
Live Secret Key Stripe Dashboard → Toggle to Live mode → API Keys → Secret key Live Only
Live Webhook Secret Stripe Dashboard → Developers → Webhooks → Live Endpoint → Signing Secret Live Only
4

Configure General Rules Tab

Click the General Rules tab to set post-payment automation behavior.

Setting Description
Auto-Confirm Booking When enabled, a booking automatically moves from Pending to Confirmed the moment payment is verified by the webhook. Recommended: ON.
Currency Set to PHP for Philippine Peso. Only change this if your business accepts payments in a different currency (e.g., USD for international customers).
5

Test the API Connection

Use the "Test GCash API" or "Test Stripe API" button inside each gateway tab. This pings the payment provider's live API to verify your keys are correct before saving.

What the connection test verifies:
  • Your Secret Key is syntactically correct and valid
  • ELFAA's server can reach the payment provider's API
  • Your account is active and not suspended
✅
A green "API Connection Verified!" popup confirms your keys are working. You can now safely save and proceed to test a payment.
6

Save Payment Settings

Click the red "Save Payment Settings" button at the bottom of the page. A SweetAlert2 success popup confirms the settings have been saved to the database.

ℹ️
The amber "Unsaved changes" indicator in the action bar will appear whenever you make edits. The Discard button reverts all unsaved changes to the last saved state.
🔗 Webhook Reference

Webhook Setup & Reference

Webhooks are the bridge between the payment provider and ELFAA. When a customer pays, the provider sends a secure POST request to ELFAA, which auto-confirms the booking. Below are the exact URLs and events to register.

📱 PayMongo Webhook

Register in PayMongo Dashboard → Settings → Webhooks

Endpoint URL/api/webhooks/paymongo
HTTP MethodPOST
Signature HeaderPayMongo-Signature
CSRF Exempt✓ Yes (built-in)
payment.paid✓ Subscribe
payment.failed✓ Subscribe
source.chargeable✓ Subscribe

💳 Stripe Webhook

Register in Stripe Dashboard → Developers → Webhooks

Endpoint URL/api/webhooks/stripe
HTTP MethodPOST
Signature HeaderStripe-Signature
CSRF Exempt✓ Yes (built-in)
checkout.session.completed✓ Subscribe
payment_intent.succeeded✓ Subscribe
payment_intent.payment_failed✓ Subscribe
⚠️
Important: Webhook URLs must be publicly accessible HTTPS URLs. Replace yourdomain.com with your actual domain. For local testing, use ngrok: run ngrok http 8000 and register the ngrok HTTPS URL (e.g., https://abc123.ngrok.io/api/webhooks/stripe).
🔎
Stripe CLI — Local Webhook Testing:
# Install Stripe CLI, then run: stripe login stripe listen --forward-to localhost:8000/api/webhooks/stripe # The CLI prints a webhook signing secret — use that in your admin settings. # Trigger test events manually: stripe trigger checkout.session.completed

🚀 Going Live

Switching to Live Mode

Once you've confirmed everything works in Test Mode, follow this checklist to enable real payments from customers.

1

Confirm Business Verification is Complete

Check both PayMongo and Stripe dashboards for any pending action items or document requests. Both must show a Verified or Active status before Live Mode keys will work.

2

Register Live Webhook Endpoints

In both PayMongo and Stripe dashboards, create separate Live webhook endpoints pointing to your production server. Your domain must have valid HTTPS/SSL.

# Replace with your actual production domain: https://elfaa-car-rental.com/api/webhooks/paymongo https://elfaa-car-rental.com/api/webhooks/stripe
3

Enter Live API Keys in Admin Dashboard

Go to ELFAA Admin → Payment Settings. In both gateway tabs, fill in the Live Keys fields, then switch Processing Mode to Live Mode and save.

🔐
Double-check that you're entering Live Keys (starting with pk_live_ / sk_live_) — NOT the Test Keys. Using test keys in Live Mode causes payment failures for real customers.
4

Run a Small Live Test Payment

Make one real payment with a real GCash account or actual credit card. Verify the transaction appears in both the ELFAA admin and the payment provider's live dashboard. Then refund yourself.

✅
Once the live payment confirms and the booking auto-confirms in admin — you're fully live! Announce payment availability to your customers.
5

Ongoing Monitoring

  • ELFAA Bookings Log — confirm booking statuses update correctly after payments
  • PayMongo Dashboard → Payments — verify amounts and settlement dates
  • Stripe Dashboard → Payments — monitor for any declined charges or disputes
  • Webhook delivery logs in both dashboards — all responses should be 200 OK
  • ELFAA payment_transactions table — all records should have correct status values
⚠️
Emergency Rollback: If anything goes wrong, go to ELFAA Admin → Payment Settings and toggle the affected gateway to Disabled. This instantly removes the payment option from customer-facing pages — no code changes or server restart required.
